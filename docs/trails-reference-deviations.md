**DEV-20 — Native distance controls (September 16, 2026):** The filter sheet translates Figma's two-thumb distance range into two native Compose Sliders labeled **Minimum distance** and **Maximum distance**. The pinned Material RangeSlider assigns generic labels and numeric state descriptions to private actionable thumb parents; custom thumb semantics cannot replace them. Separate sliders retain native adjustment actions, Trails colors, one-kilometer steps, the ordered minimum/maximum constraint, and the 30 km upper position meaning no maximum. This places each control's label and kilometer/no-maximum state on its actionable semantics modifier. The extra vertical space is an intentional accessibility translation. [Capture 106](evidence/m1/android/production/106-final-sliders-large-text-top.png) shows both controls at 200%, including a cleanly wrapped maximum label; [capture 107](evidence/m1/android/production/107-final-sliders-large-text-actions.png) shows the endpoint controls, feature labels and complete Show/Cancel actions above system navigation. This closes that bounded large-text visual check; installed adjustment, TalkBack focus/traversal and speech are not established by these screenshots.

The M1 design/state specification and durable source handoff are complete within this bounded design pass. C2's final platform-selection row remains open for full-product acceptance.
